> Статус: **в работе.** Фундамент (волна 0) и #1 «Сегодня» — в проде за флагом `WIDGETS_USERS`
> (FR-49, W-INV-1…8 и D-43…D-52 — в SPEC). Отчёт ночи 10→11.11 — §8.
> Каталог того, что даёт Bot API 10.4 (9.11.2026) burnfat.
> Отобранное владельцем переезжает в SPEC (FR/INV/D) и MINIAPP-SPEC до кода — как всё остальное.
> Источник по возможностям: [core.telegram.org/bots/widgets](https://core.telegram.org/bots/widgets),
> [api-changelog#november-9-2026](https://core.telegram.org/bots/api-changelog).

## 1. Что это и чем отличается от того, что уже есть

Виджет — отдельный тип сообщения (`sendWidget`): HTML + CSS + JS, нарисованный прямо в пузыре
чата. Не разметка текста — это уже умеют rich-сообщения, на которых стоит весь бот (D-31).

| | Rich-сообщение (сейчас) | Виджет (10.4) | Mini App |
|---|---|---|---|
| Где живёт | в ленте чата | в ленте чата | отдельный экран |
| Графика | текст, бары символами, таблицы | SVG, canvas, настоящие графики | всё |
| Реакция на тап | только callback-кнопки под сообщением → бот перерисовывает | мгновенно, внутри пузыря, без бота | мгновенно |
| Ввод текста | ответом в чат | **нет** (`input` вырезан) | есть |
| Сеть | — | **нет**; только `TelegramWidget.request()` → бот | своя |
| Размер | 4096 символов | 4 КБ HTML после zlib, высота ≤ 600 px, без скролла | без ограничений |

**Вывод:** виджет закрывает дыру между rich-сообщением и аппкой. Rich остаётся для текста и
реплик; виджет берёт то, где нужна **графика или мгновенная реакция на тап**; аппка — то, где
нужен **ввод, поиск или длинный список**.

## 2. Ограничения, которые определяют дизайн

- **Нет полей ввода.** Граммы и вес — только степперами ±, выбор — кнопками-чипами.
- **Нет сети.** Всё, что виджету нужно, приходит в `chat_data` (JSON ≤ 1 КБ на сообщение)
  или ответом бота на `request()` (≤ 1 КБ, ответ за 15 с, 5 запросов за 5 с, один в полёте).
- **Состояние пишет только бот:** `editMessageWidgetData` перерисовывает виджет на месте.
- **Только личный чат с ботом**, переслать нельзя (protected content). Для двух людей не помеха.
- **Картинок почти нет:** только `data:` и inline SVG в бюджете 4 КБ — фото блюда не влезет.
- **Мост в аппку:** `TelegramWidget.openTelegramLink('https://t.me/…')` — тап в виджете может
  открыть Mini App на нужном экране, как кнопка FR-46.

## 3. Архитектура (общая для всех кейсов)

**Шаблон отдельно, данные отдельно.** HTML — статический файл на тип виджета
(`app/bot/widgets/<имя>.html`), цифры конкретного сообщения — в `chat_data`. Тогда обновление —
это `editMessageWidgetData` с новым JSON, а не новое сообщение; шаблон не пересобирается на
каждый день. Альтернатива — вшивать цифры в HTML — даёт новое сообщение на каждое изменение
и перерасход 4 КБ.

```
бот: сервис app/application/* ─► собрать JSON (≤1 КБ) ─► sendWidget(шаблон, chat_data)
                                                          │
виджет: рисует из chat_data, тап ─► request("a:42:+10") ─► widget_query ─► тот же сервис
                                                          ◄── answerWidgetQuery(JSON) ◄─┘
                                       editMessageWidgetData — если меняется сам день
```

**Транспорт.** aiogram 3.31 не знает `sendWidget`, `answerWidgetQuery`, `widget_query`
(метод вышел 9.11.2026). Вызов — свой подкласс `TelegramMethod` или прямой POST; апдейты
`widget_query` — проверить, пропускает ли aiogram неизвестный тип апдейта при поллинге
(`allowed_updates`). **Это первый спайк** — без него запросы из виджета не работают.

### Предлагаемые инварианты (W-INV)

- **W-INV-1. Числа считает Python.** JS только показывает и даёт предпросмотр (± граммы ×
  запиннутая плотность). Истина — ответ бота после записи; виджет перерисовывается им
  (INV-1, MA-INV-1). `resolve_grams`, Атвотер, пиннинг — в JS не повторяются.
- **W-INV-2. Подпись — фолбэк.** У каждого виджета caption с главной цифрой дня текстом: как
  виджет рисуют старые клиенты, документация не говорит.
- **W-INV-3. Бюджет в гейте.** Тест: каждый шаблон ≤ 4096 байт после `zlib.compress(…, 9)`,
  каждый собранный `chat_data` ≤ 1024 байт на худших данных. Красное — деплоя нет.
- **W-INV-4. Граница доверия — `widget_query`.** `data` (≤ 64 байт) разбирается строго по
  формату; владелец записи сверяется с `from.id` запроса (FR-19). Чужой id — отказ.
- **W-INV-5. Мутация идемпотентна.** В `data` — ключ операции; повтор не пишет дважды (§7.5 MA).
- **W-INV-6. Запись не стирает виджет.** Пока запрос в полёте — кнопка в busy-состоянии,
  остальное на месте (аналог MA-INV-32).
- **W-INV-7. Только цвета темы** (`--tg-theme-*`, `light-dark()`), проверка в светлой и тёмной
  теме и на ширинах 200 px и максимум пузыря (аналог правила 320/1100, §5.1 CLAUDE.md).
- **W-INV-8. Высота ≤ 600 без скролла.** Длинное — топ-N + «ещё в приложении» через
  `openTelegramLink`.

## 4. Каталог кейсов

Сложность: **S** — только показ (`chat_data`), без запросов; **M** — нужны запросы к боту

### 4.3 Что НЕ переносим — и почему

| Что | Почему остаётся в аппке / в тексте |
|---|---|
| Каталог-редактор, поиск продуктов | Поиск — это ввод текста; 229+ строк не влезают в 600 px без скролла. |
| Слияние дублей | Необратимо (§7.7 MA): нужен обзор и подтверждение, не пузырь в ленте. |
| Чат с ассистентом | Ввод текста и стриминг уже в чате (FR-45). Графиком — только ответ (#17). |
| Ввод еды текстом и голосом | Это и есть чат; виджет — после ввода (#11), не вместо. |
| Фото блюда в карточке | Картинки только `data:` в 4 КБ — фото не влезает. |
| Рецепты с составом | Ингредиенты вводятся текстом; виджет может показать состав, правка — в аппке. |
| Короткие реплики (TZ, багрепорт, пикеры) | Это не экраны; rich/текст справляется (D-31). |

## 6. Открытые вопросы

- ~~**OQ-W1.**~~ **Ответ (11.11, D-45):** нет — aiogram 3.31 кладёт `widget_query` в
  `Update.model_extra` и роняет его как «unknown update type», а без явного `allowed_updates`
  Telegram его и не шлёт. Решение: `allowed_updates` явно + outer-middleware `dp.update`.
  Живая доставка подтверждается строкой лога `widget: запрос …` при первом показе виджета.
- **OQ-W2.** Как виджет показывают клиенты старше 13.2? Документация молчит → W-INV-2 до замера.

  каждого апдейта человека; тяга — один фоновый запрос при появлении виджета на экране (не раз
  в 5 с): закрывает записи из аппки и рестарт бота.
- ~~**OQ-W4.**~~ **Решено 10.11.2026 (D-43):** «📊 Сегодня» заменяется виджетом целиком; rich —
